📌 Project Description

This project focuses on data visualization using the country_wise_covid_19_data.csv dataset. Various plots such as scatter, line, pair, and categorical plots were created using Seaborn to explore relationships between confirmed, recovered, deaths, and new cases.

Pandas used for data handling, and Matplotlib acted as the visualization backend.


It is part of my COVID-19 Data Visualization Project, aimed at practicing data analysis and visualization techniques with Python.
